# Quetta Dry Cleaners - User Manual

## 1. Dashboard

- View today's orders, sales, processing pipeline, outstanding payments, and expenses.
- Use quick actions to jump to New Order, Customers, Payments, Expenses, and Orders.

## 2. New Order

- Select existing customer or enter new customer data.
- Set expected date, delivery mode, and payment method.
- Add services from the preloaded rate list.
- Quantity x Rate auto-calculates item amount.
- Subtotal, discount, grand total, paid amount, and remaining balance are auto-calculated.
- Use Confirm / Save Order.

## 3. Orders

- Search by order number, customer name, or phone.
- Filter by order status and payment status.
- Double-click a row to open details panel.
- Update status and print/reprint receipts.
- Delete only after confirmation.

## 4. Customers

- Add and search customers.
- Outstanding balances are computed from linked orders.

## 5. Services (Rate List)

- Add new services with category, unit, and rate.
- Toggle service active/inactive.
- Edit rates for future orders.

## 6. Payments

- Select order and add additional payment.
- Payment history is appended, not overwritten.
- Order paid and remaining values auto-update.

## 7. Expenses

- Record expense category, description, amount, and notes.
- Track daily and monthly expenses.

## 8. Reports

- Review daily sales, outstanding totals, net sales/profit overview, and service-wise sales.

## 9. Settings

- Update business profile, logo path, receipt options, and currency/date format.
- Use Backup Database and Restore Database in desktop EXE mode.

## 10. Backup and Restore

- Backup: choose destination file path and save DB copy.
- Restore: choose a backup DB file and restore all data.

## 11. Data Safety

- Data is persisted after each operation.
- Destructive actions ask confirmation.
- Empty optional fields are supported.
